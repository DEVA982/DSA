<h2><a href="https://www.geeksforgeeks.org/problems/stable-marriage-problem/1">Stable Marriage Problem</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">You are given two arrays <strong>men[]</strong> and <strong>women[]</strong>, each of length <strong>n</strong>, where:</span></p>
<ul>
<li><span style="font-size: 18.6667px;"><strong>men[i]</strong> represents the preference list of the i-th man, ranking all women in order of preference.</span></li>
<li><span style="font-size: 18.6667px;"><strong>women[i]</strong> represents the preference list of the i-th woman, ranking all men in order of preference.</span></li>
</ul>
<p><span style="font-size: 18.6667px;">The task is to form <strong>n</strong> pairs (marriages) such that e</span><span style="font-size: 18.6667px;">ach man is matched with exactly one woman, and each woman is matched with exactly one man.</span></p>
<p><span style="font-size: 18.6667px;">A matching is stable if there is no pair (man, woman) who both prefer each other over their current partners. Consider two men, m1 and m2, and two women, w1 and w2. Their preference lists are as follows:<br><br>&nbsp; &nbsp; m1 prefers w1 over w2, and m2 prefers w1 over w2.<br>&nbsp; &nbsp; w1 prefers m1 over m2, and w2 prefers m1 over m2.<br><br>The matching {(m1, w2), (m2, w1)} is not stable because m1 and w1 prefer each other over their assigned partners. In contrast, the matching {(m1, w1), (m2, w2)} is stable, as no two individuals would rather be with each other than their assigned partners.</span></p>
<ul>
<li><span style="font-size: 18.6667px;">It is guaranteed that a stable matching always exists. </span></li>
<li><span style="font-size: 18.6667px;">There can be multiple stable matching. For the sake of consistency, we need to produce output prioritizing men's preferences over women.&nbsp;&nbsp;</span></li>
<li><span style="font-size: 18.6667px;">Return an array result[] of size n, where result[i] denotes the index (0-based) of the woman matched with the i-th man.</span></li>
</ul>
<p><span style="font-size: 14pt;"><strong>Examples:</strong>&nbsp;</span></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> n = 2, men[] = [[0, 1], [0, 1], women[] = [[0, 1], [0, 1]]<br><strong>Output:&nbsp;</strong>[0, 1]<br><strong>Explanation:<br></strong></span><span style="font-size: 14pt;">Man 0 is married to Woman 0 (his first choice and her first choice).<br></span><span style="font-size: 14pt;">Man 1 is married to Woman 1 (his second choice and her second choice).</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input:  </strong> n = 3, men[] = [[1, 0, 2], [2, 1, 0], [0, 2, 1]], women[] = [[1, 0, 2], [2, 1, 0], [0, 2, 1]]<strong><br>Output:  </strong> [1, 2, 0]<strong><br>Explanation: </strong> The output array represents women numbers assigned to men. There are three stable solutions to this matching arrangement:<br>    Men get their first choice and women their third – (1, 2, 0)<br>    All participants get their second choice – (0, 1, 2);<br>    Women get their first choice and men their third – (2, 0, 1).<br>As per the question,  we need to find a match that is best suited for men, so we produce output as [1, 2, 0]</span><span style="font-size: 14pt;"><br></span></pre>
<p><span style="font-size: 14pt;"><strong>Constraints:</strong>&nbsp;<br></span><span style="font-size: 14pt;">2 ≤ n ≤ 10<sup>3<br></sup></span><span style="font-size: 14pt;">0 ≤ men[i] ≤ n - 1<br></span><span style="font-size: 14pt;">0 ≤ women[i] ≤ n - 1</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Greedy</code>&nbsp;
