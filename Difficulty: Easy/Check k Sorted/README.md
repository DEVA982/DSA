<h2><a href="https://www.geeksforgeeks.org/problems/k-sorted-array1610/1">Check k Sorted</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">Given an array of&nbsp;<strong>n</strong> distinct elements. Check whether the given array is a k-sorted&nbsp;array or not. A k-sorted&nbsp;array is an array where each element is at most&nbsp;k distance away from its target position in the sorted array.&nbsp;</span></p>
<p><span style="font-size: 18px;"><strong>Examples</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = {3, 2, 1, 5, 6, 4}, k = 2
<strong>Output:</strong> true
<strong>Explanation</strong>: Every element is at most 2 distance away from its target position in the sorted array.  </span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = {13, 8, 10, 7, 15, 14, 12}, k = 1
<strong>Output:</strong> false</span>
</pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ n ≤ 10<sup>5</sup><br>0 ≤ k &lt; n</span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>Binary Search</code>&nbsp;
